# Подсчёт товаров на полке — запуск на Windows и RTX 4070 Ti

Эта сборка настроена под ваш ПК: **Intel Core i9-11900K, 32 ГБ RAM и NVIDIA RTX 4070 Ti 12 ГБ**. Обучение выполняется через CUDA, а не на процессоре.

## Самая короткая последовательность

1. Распаковать проект в короткий путь без кириллицы, например `C:\CV\shelf_product_counter_windows`.
2. Установить **Python 3.11 x64** с официального сайта Python. В установщике оставить включённым Python Launcher.
3. Обновить драйвер NVIDIA и перезагрузить ПК.
4. Дважды нажать `01_SETUP_WINDOWS.bat`.
5. Перенести подготовленный датасет с Mac **или** запустить `START_WINDOWS.bat` → пункт 2.
6. Запустить `START_WINDOWS.bat` → пункт 3 → модель 1 (YOLO11).
7. После успешных двух эпох запустить остальные четыре модели.
8. Затем пункт 4 для полного обучения и пункт 5 для итоговых метрик.

---

## 1. Куда распаковать

Лучший вариант:

```text
C:\CV\shelf_product_counter_windows
```

Не рекомендуется распаковывать глубоко в `Рабочий стол\Университет\...`: у Windows иногда возникают проблемы с длинными путями.

На диске желательно иметь минимум **50–80 ГБ свободного места**. При повторной подготовке датасета изображения копируются в папку проекта.

## 2. Установка

Запустите двойным щелчком:

```text
01_SETUP_WINDOWS.bat
```

Скрипт:

- создаст `.venv` на Python 3.11;
- установит PyTorch 2.11 с CUDA 12.8;
- установит Ultralytics и остальные зависимости;
- проверит, что PyTorch видит RTX 4070 Ti.

Успешный конец выглядит примерно так:

```text
CUDA available: True
GPU: NVIDIA GeForce RTX 4070 Ti
VRAM: 12.0 GB
ВСЕ ГОТОВО: CUDA работает.
```

Отдельный CUDA Toolkit вручную для этой сборки устанавливать не требуется. Нужен исправный современный драйвер NVIDIA.

## 3. Как перенести датасет с Mac

На Mac вы уже получили готовую папку:

```text
data/sku110k
```

Самый быстрый вариант — скопировать **всю папку `sku110k`** с Mac и положить на ПК сюда:

```text
C:\CV\shelf_product_counter_windows\data\sku110k
```

Проверка: должен существовать файл

```text
data\sku110k\sku110k.yaml
```

И папки:

```text
data\sku110k\images\train
data\sku110k\images\val
data\sku110k\images\test
data\sku110k\labels
data\sku110k\annotations
```

В этом случае повторно готовить датасет не надо. При первом запуске проекта путь внутри `sku110k.yaml` автоматически заменится с macOS-пути на текущий Windows-путь.

### Если переносите сырой SKU-110K

Скопируйте на ПК исходные папки `images` и `annotations`. Затем:

1. запустите `START_WINDOWS.bat`;
2. выберите `2 — подготовить SKU-110K`;
3. перетащите папку `images` в окно;
4. перетащите папку `annotations`;
5. выберите режим `1 — копировать`.

После завершения появится `data\sku110k\sku110k.yaml`.

## 4. Главное меню

Запускайте:

```text
START_WINDOWS.bat
```

В меню есть:

```text
1 — проверить CUDA и видеокарту
2 — подготовить SKU-110K
3 — быстрый тест одной модели
4 — полное обучение одной модели
5 — оценить модель и построить карту ошибок
6 — посчитать товары на своей фотографии
7 — открыть папку результатов
```

## 5. Первый запуск

Сначала:

```text
пункт 3 → модель 1 — YOLO11
```

Быстрый режим использует 2 эпохи и часть train. Он нужен только для проверки, что код, датасет и CUDA работают.

Результаты сохраняются внутри проекта:

```text
runs_windows_quick\yolo11\weights\best.pt
```

При повторном запуске Ultralytics может создать `yolo112`, `yolo113` и так далее. Меню автоматически находит самый свежий `best.pt`.

## 6. Проверить пять архитектур

В пункте 3 по очереди запустите:

1. YOLO11;
2. RT-DETR-L;
3. Faster R-CNN;
4. RetinaNet;
5. SSDLite.

Запускайте строго по одной модели. RT-DETR-L, Faster R-CNN и RetinaNet тяжелее YOLO. В конфиге для них уже установлен безопасный `batch_size: 1`.

Если возникает `CUDA out of memory`:

1. закройте игры, браузер с аппаратным ускорением и приложения, использующие видеокарту;
2. перезапустите модель;
3. при повторной ошибке откройте `configs\windows_full.yaml` и не увеличивайте batch size.

## 7. Полное обучение

После быстрых тестов:

```text
пункт 4 → выбрать модель
```

Полный режим использует 20 эпох и весь train-набор. Результаты:

```text
runs_windows_full\<модель>
```

Для методически честного сравнения используйте одинаковый split и одинаковое число эпох. Четыре модели работают на входе 640×640. SSDLite по своей архитектуре использует 320×320 — это обязательно отметить в отчёте.

## 8. Итоговые метрики и ошибки

После обучения каждой модели:

```text
пункт 5 → выбрать модель
```

Меню предложит последние найденные веса. Для пробного запуска можно проверить 100 test-изображений. Для итоговой таблицы введите `0`, чтобы проверить весь test.

Будут рассчитаны:

- mAP@0.5;
- mAP@0.5:0.95;
- precision, recall и F1 при IoU 0.5;
- Count MAE и Count RMSE;
- средняя относительная ошибка подсчёта;
- Count MAE на плотных сценах;
- среднее время кадра и FPS.

Общая таблица:

```text
report\experiment_results.csv
```

Три сцены с наибольшей ошибкой подсчёта:

```text
runs_windows_full\evaluation\<модель>\errors
```

Цвета:

- зелёный — правильная детекция;
- красный `MISS` — пропуск;
- синий `FP` — ложное срабатывание.

## 9. Своя фотография полки

Запустите:

```text
пункт 6 → модель → фотография
```

Можно перетащить собственную фотографию магазинной полки в окно. Результат откроется автоматически и сохранится в:

```text
demo\result_<модель>.jpg
```

На своей фотографии модель покажет рамки и количество товаров. Пропуски и ложные срабатывания автоматически отмечаются только на размеченном test-наборе SKU-110K.

## 10. Где менять параметры

Быстрый режим:

```text
configs\windows_quick.yaml
```

Полный режим:

```text
configs\windows_full.yaml
```

Настройки под RTX 4070 Ti уже выставлены консервативно. Для начала ничего в них не меняйте.

## 11. Если обучение прервалось

Для YOLO и RT-DETR в Ultralytics остаётся `last.pt`. Возобновление можно выполнить из терминала проекта, например:

```bat
.venv\Scripts\python.exe src\train_ultralytics.py --config configs\windows_full.yaml --model yolo11 --resume
```

Для Torchvision:

```bat
.venv\Scripts\python.exe src\train_torchvision.py --config configs\windows_full.yaml --model fasterrcnn --resume
```
