# Shelf Product Counter

Учебный проект детекции и автоматического подсчёта товаров на полке на датасете SKU-110K.

Архитектуры:

1. YOLO11;
2. RT-DETR-L;
3. Faster R-CNN ResNet-50 FPN v2;
4. RetinaNet ResNet-50 FPN v2;
5. SSDLite MobileNetV3.

Для запуска на Windows откройте `START_HERE_WINDOWS.md`, затем выполните `01_SETUP_WINDOWS.bat` и `START_WINDOWS.bat`.
